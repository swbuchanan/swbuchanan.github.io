## Other projects

- [Implied probability distributions for asset prices]({{< ref "/posts/implied_stock_distributions.md" >}}). This was a data analysis project for a computational quantitative finance course.
- [Timed mental arithmetic practice](https://arithmetic.stevenbuchanan.net/). This is a simple typescript app that you can use to practice mental arithmetic. Especially useful for those applying to quantitative trading jobs. I created it because I wanted more customizability for the problem generator than I was finding on other arithmetic trainers. I hoped to keep it extremely simple to use, but that goal conflicts somewhat with maximum customizability. This project is essentially complete I add a feature or two to this when I think of it and have time.
